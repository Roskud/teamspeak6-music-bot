# 🐧 VibeSpeak — Полное руководство по установке на Linux VPS (Debian / Ubuntu)

Подробная пошаговая инструкция для установки музыкального бота **VibeSpeak** на любой VPS/VDS под управлением **Debian 10 / 11 / 12** или **Ubuntu 20.04 / 22.04 / 24.04**.

---

## 📋 Что нужно перед началом

1. **Сервер VPS/VDS** с чистым Debian или Ubuntu (достаточно даже минимального тарифа: 1 CPU, 512–1024 МБ RAM).
2. **TeamSpeak 3 или TeamSpeak 6 сервер**:
   * **Вариант А (Сервер на этом же VPS)**: Если TeamSpeak сервер запущен на этом же VPS (IP `127.0.0.1`), вам понадобится пароль от пользователя `serveradmin` (он выдаётся в консоли при первом запуске `ts3server`).
   * **Вариант Б (Сервер на другом IP)**: Внешний IP адрес сервера и пароль `serveradmin` для подключения через ServerQuery.

---

## 🚀 Установка в 1 команду

Подключитесь к вашему VPS по SSH под пользователем `root` и запустите одну команду:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/Roskud/teamspeak6-music-bot/main/debian-vps/install.sh)"
```

*(Скрипт сам автоматически скачает актуальные файлы, установит все зависимости, настроит виртуальное окружение, защитит от заикания звука и запустит бота как системную службу).*

Либо через клонирование репозитория:
```bash
git clone https://github.com/Roskud/teamspeak6-music-bot.git
cd teamspeak6-music-bot/debian-vps
chmod +x install.sh
sudo ./install.sh
```

---

## ⚙️ Что спросит мастер установки

В процессе установки скрипт задаст 5 простых вопросов:

1. **Адрес TeamSpeak сервера** (`127.0.0.1` по умолчанию):
   * Если сервер запущен на этом же VPS — просто нажмите **Enter**.
   * Если сервер на другом VPS — введите его IP или домен (например `123.45.67.89`).
2. **Голосовой порт** (`9987` по умолчанию):
   * Обычно стандартный порт `9987` (нажмите **Enter**).
3. **Порт ServerQuery** (`10011` по умолчанию):
   * Стандартный порт управления `10011` (нажмите **Enter**).
4. **Пароль serveradmin**:
   * Введите пароль администратора ServerQuery.
   * *Где его взять?* Если вы только что создали TS3 сервер, пароль был напечатан при первом старте сервера. Если вы его забыли, на локальном сервере его можно сбросить параметром `serveradmin_password=ваш_пароль` при запуске `ts3server`.
5. **Токен Яндекс.Музыки**:
   * Вставьте токен для прослушивания полных треков целиком (без лимита в 30 секунд).
   * Если токена пока нет, нажмите **Enter** (можно добавить позже).

## 🎛️ Управление ботом на VPS (Утилита vibespeak)

После установки на сервере доступна удобная команда `vibespeak` (работает из любой папки):

```bash
vibespeak status   # Посмотреть статус бота (работает / ошибка)
vibespeak logs     # Открыть живые логи в реальном времени (Ctrl+C для выхода)
vibespeak restart  # Перезапустить бота
vibespeak token    # Открыть файл токена Яндекс.Музыки в nano
vibespeak config   # Изменить IP сервера или пароль serveradmin
vibespeak stop     # Остановить бота
vibespeak start    # Запустить бота
```

Также работают стандартные системные команды:
```bash
sudo systemctl status ts3audiobot
sudo journalctl -u ts3audiobot -f
sudo systemctl restart ts3audiobot
```

## 🔍 Решение возможных проблем (Troubleshooting)

### 1. Бот не заходит на сервер (Connection refused)
* Проверьте, запущен ли сам TeamSpeak сервер:
  ```bash
  ss -tuln | grep -E '9987|10011'
  ```
* Если сервер на другом VPS, убедитесь, что в фаерволе (UFW / iptables) открыты порты `9987/udp` и `10011/tcp`.
* Проверьте конфигурацию через `vibespeak config`.

### 2. Бот зашел, но не реагирует на команды (!play, !bot add)
* Проверьте логи через `vibespeak logs`.
* Самая частая причина: **неверный пароль `serveradmin`**. Шлюз `ym_bridge.py` подключается к ServerQuery для чтения чата и очередей. Если пароль не подошел, введите правильный через:
  ```bash
  vibespeak config
  ```
  и перезапустите:
  ```bash
  vibespeak restart
  ```

### 3. Треки играют только по 30 секунд (превью)
* Вы не указали токен Яндекс.Музыки.
* Получите бесплатный токен (см. инструкцию в основном `README.md`) и вставьте его:
  ```bash
  vibespeak token
  ```
  После сохранения бот автоматически перезапустится и включит полные версии треков.

## 📂 Пути к файлам на сервере

* Директория бота: `/opt/ts3audiobot`
* Конфигурация шлюза: `/opt/ts3audiobot/bridge_config.json`
* Токен Яндекс.Музыки: `/opt/ts3audiobot/yandex_token.txt`
* Конфигурация ядра бота: `/opt/ts3audiobot/bots/default/bot.toml`
* Логи: `/opt/ts3audiobot/logs` и `journalctl -u ts3audiobot`
